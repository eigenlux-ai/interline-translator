Interline(行间)은 전체 코드를 공개한 이중 언어 읽기 및 번역 확장 프로그램입니다. 기사나 문서를 읽고 토론에 참여할 때, 원문과 번역을 같은 페이지에서 확인하세요.

■ 원문과 번역을 함께 읽기
원문 옆에 번역을 문단별로 표시합니다. 이중 언어, 번역만, 원문만 보기 중에서 선택하세요. 강조, 인용 표시, 카드 등 10가지 표시 스타일을 지원합니다. 플로팅 컨트롤, 마우스 오른쪽 버튼 메뉴 또는 Alt+T로 번역을 시작할 수 있습니다.

■ 선택한 텍스트 번역
텍스트를 선택하고 번역 아이콘을 누르면 현재 페이지에서 번역을 읽고, 복사하고, 들어볼 수 있습니다. 지원되는 AI 엔진에서는 어휘 설명을 펼쳐 용어와 문맥을 이해하는 데 도움을 받을 수 있습니다.

■ 입력창에서 바로 번역
초안을 작성한 뒤 스페이스를 세 번 누르면 입력한 자리에서 번역됩니다. 쓰기 대상 언어를 따로 설정하거나 /en 또는 en:으로 이번 번역의 언어를 지정할 수 있습니다.

■ 무료로 시작하고, 내 AI 연결하기
API 키가 필요 없는 무료 번역 엔진이 내장되어 있습니다. 내 API 키로 OpenAI, Anthropic, Google Gemini, OpenRouter 및 OpenAI / Anthropic 호환 서비스도 연결할 수 있습니다. 외부 AI 서비스에는 요금이 부과될 수 있으며, 가격·할당량·이용 가능 여부는 각 제공업체가 정합니다.

■ 나에게 맞는 설정
번역 스타일, 프롬프트, 용어집을 설정하세요. 사이트마다 자동 번역하거나 번역하지 않도록 정할 수 있습니다. 밝은 화면과 다크 모드, 12가지 인터페이스 언어를 지원합니다.

■ 데이터 처리 방식
Interline 계정 등록은 필요하지 않습니다. 행동 추적이나 텔레메트리가 없으며 번역 중계 서버도 운영하지 않습니다. 설정과 API 키는 브라우저 로컬 저장소에 보관됩니다. 번역할 텍스트는 선택한 제공업체로 직접 전송되며 해당 업체의 데이터 정책이 적용됩니다. 전체 페이지 문맥 기능을 켜면 문맥 생성을 위해 페이지 앞부분 최대 8,000자도 전송됩니다.

Chrome 내부 페이지 등 브라우저가 제한하는 페이지에는 번역을 삽입할 수 없습니다. 사이트와 편집기에 따라 호환성이 다를 수 있습니다. 문제는 Issues로 알려 주세요.

AI 요청에는 관련 페이지 제목, 주변 문장, 일치하는 용어집 항목이 포함될 수 있습니다. 자동 번역 규칙에 따라 추가 클릭 없이 번역이 시작될 수 있습니다. 설정 내보내기 파일에는 API 키가 포함되므로 비공개로 보관하세요.
