Interline（行间）は、コードをすべて公開している対訳・翻訳拡張機能です。記事やドキュメントを読むときも、議論に参加するときも、原文と訳文を同じページで確認できます。

■ ページ全体を対訳で読む
原文のそばに訳文を段落ごとに表示。対訳・訳文のみ・原文のみの3つの表示を切り替えられます。ハイライト、引用バー、カードなど10種類の表示スタイルに対応。フローティングコントロール、右クリックメニュー、Alt+T から翻訳を開始できます。

■ 選択したテキストを翻訳
テキストを選択し、翻訳アイコンをクリック。そのページで訳文を確認、コピー、読み上げできます。対応する AI エンジンでは、語句の解説を開いて用語や文脈の理解を深められます。

■ 入力欄でそのまま翻訳
下書きを入力したら、スペースを3回押して翻訳。入力欄の翻訳先言語を別途設定でき、/en や en: で今回だけの翻訳先言語も指定できます。

■ 無料で始めて、自分の AI も使える
API キー不要の無料翻訳エンジンを内蔵。自分の API キーで OpenAI、Anthropic、Google Gemini、OpenRouter、および OpenAI / Anthropic 互換サービスにも接続できます。外部 AI サービスは有料の場合があり、料金・利用枠・提供状況は各サービスによって異なります。

■ 自分好みに設定
翻訳スタイル、プロンプト、用語集をカスタマイズ。サイトごとに自動翻訳や翻訳しない設定ができます。ライト・ダーク表示と12種類のインターフェース言語に対応しています。

■ データの取り扱い
Interline のアカウント登録は不要です。行動追跡やテレメトリーはなく、翻訳の中継サーバーも運営していません。設定と API キーはブラウザ内に保存されます。翻訳対象のテキストは選択したサービスへ直接送信され、そのサービスのデータポリシーが適用されます。「ページの文脈を参照」を有効にすると、文脈生成のためにページ先頭の最大 8,000 文字も送信されます。

Chrome の内部ページなど、ブラウザが制限するページでは翻訳を挿入できません。サイトやエディターによって動作が異なる場合があります。問題は Issues でお知らせください。

AI リクエストには関連するページタイトル、周辺の文章、該当する用語集の項目が含まれる場合があります。自動翻訳ルールにより、再度のクリックなしに翻訳を開始することがあります。設定の書き出しファイルには API キーが含まれるため、非公開で保管してください。
